 🐾 RescueConnect – A Centralized Animal Safety Reporting System

RescueConnect is a full-stack MERN web application designed to support animal rescue operations, pet adoption services, volunteer coordination, emergency medical assistance, and animal abuse reporting through a centralized digital platform.

The platform connects rescuers, adopters, volunteers, and animal welfare supporters through an interactive and responsive system. Users can report rescue cases, track rescue requests using unique tracking IDs, explore pets for adoption, request medical help, report abuse incidents, and interact with an intelligent chatbot that guides users to the appropriate services.

RescueConnect was developed with a focus on accessibility, responsiveness, security, and user-friendly navigation to improve coordination in animal welfare activities.

 ⚙️ How It Works

1. Users register or log into the platform securely.
2. Rescue cases can be submitted through the Rescue module.
3. The system automatically detects the user's location during rescue submissions.
4. The backend generates a unique tracking ID for each rescue request.
5. Rescue and user data are stored securely in MongoDB.
6. Users can browse pets available for adoption.
7. Volunteers can explore volunteering opportunities and participate in rescue support activities.
8. Medical assistance requests can be submitted through the Medical Help section.
9. Nearby veterinary clinics are displayed for emergency support.
10. Abuse incidents involving animals can be reported using the Abuse Detection module.
11. The chatbot guides users to the appropriate service page based on their needs.
12. Responsive frontend ensures accessibility across all devices.
